cli.py
  main() - Parses command-line arguments (file, --steps, --rules, --format, --output), runs load, apply, validate and write in order, and exits 0 if all records pass, 1 if any fail, 2 on ValueError or FileNotFoundError.

data_loader.py
  load_csv(path) - Reads a CSV file, checks that the header has id, name, value and timestamp, and returns the rows as a list of dicts.
  load_json(path) - Reads a JSON file and returns its contents, raising ValueError if the top level is not an array.
  load(path) - Picks load_csv or load_json from the file extension and raises ValueError for any other extension.

  to_text(report) - Joins the lines from _text_lines into one string.
  to_json(report) - Converts a ValidationReport to an indented JSON string with overall counts and a per-record list.
  write(report, fmt="text", dest=None) - Formats the report as JSON or text and writes it to the dest file, or prints it to stdout if dest is None.

  register.decorator(fn) - Inner decorator that adds fn to the registry and returns it unchanged.
  normalize_value(record) - Returns a copy of the record with "value" cast to float, or 0.0 if it is missing or not numeric.
  strip_whitespace(record) - Returns a copy of the record with leading and trailing whitespace removed from every string field.
  add_flag(record) - Returns a copy of the record with a boolean "flagged" field that is True when value is greater than 100.
  apply(records, steps) - Runs the named transformations over all records in the given order, and raises ValueError if any step name is unknown.
